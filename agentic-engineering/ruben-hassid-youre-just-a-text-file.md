# "You're Just a Text File" — Stimme als komprimierte Datei

Kernthese: Persönliche Stimme, Schreibstil und Persönlichkeit lassen sich in eine Textdatei destillieren, die AI-Systeme dazu bringt, so zu schreiben und zu denken wie du.

---

**Zwei Phasen:**

1. **Extraktion** — 100 Interview-Fragen in 7 Kategorien: Überzeugungen, Schreibmechanik, ästhetische Vorlieben, Stimme, Struktur, Hard Refusals, Red Flags → ~20.000 Wörter Output
2. **Kompression** — 20.000 Wörter → 2.000–5.000 Token Reference File, optimiert für AI-Konsum

**Kompressions-Test:** "If this line disappeared, would the AI write differently? If yes, keep it."

**Struktur des Voice Profile:**
- Identity Context
- Writing Laws
- Communication Laws
- Hard Refusals
- Taste Preferences
- Phrase Bank
- Signature Tells
- Decision Rules

**Implementierung:** Komprimierte Markdown-Datei in einen Ordner legen, der via Cowork/Context mit Claude verknüpft ist — automatisch in jeder Session aktiv.

> "Patterns. Every one of them is a pattern."

Verwandt: Babic CLAUDE.md-Pattern ([[babic-journey-thousand-memories]]) — beide lösen dasselbe Problem (persistente Stimme über Context Windows) mit demselben Primitiv (Filesystem).
