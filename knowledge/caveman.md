# Caveman — Token Compression für Claude Code

Claude Code Skill und Plugin. Lässt Claude in extrem knapper Sprache kommunizieren ohne technische Präzision zu verlieren.

## Kompressionsraten

- **Output-Token:** ~75% reduziert
- **Input-Token:** ~45% reduziert (durch Memory-File-Optimierung)

## Modi

| Modus | Intensität |
|---|---|
| Lite | Leicht reduziert |
| Full | Knapp |
| Ultra | Minimal |
| 文言文 | Klassisches Chinesisch |

Intensität ist mid-conversation umschaltbar. Begleitende Skills: knappe Commit-Messages, einzeilige Code-Reviews.

## Benchmark

März 2026: "Constraining large models to brief responses improved accuracy by 26 percentage points" auf bestimmten Benchmarks — Kürze verbessert hier die Qualität, nicht nur die Kosten.

Kompatibel mit Claude Code, Cursor, Copilot, Windsurf, Cline, Codex. MIT, Python.
