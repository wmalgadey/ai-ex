# NVIDIA DLI — Kostenlose KI-Kurse

NVIDIA Deep Learning Institute bietet eine Reihe kostenloser Self-Paced-Kurse an. Alle ohne Zahlung zugänglich über [learn.nvidia.com](https://learn.nvidia.com).

## Kurse

### 1. Generative AI Explained
- Generative AI definieren und erklären wie es funktioniert
- Verschiedene GenAI-Anwendungsfelder beschreiben
- Chancen und Herausforderungen einordnen

### 2. AI for All: From Basics to GenAI Practice
- KI-Einfluss auf Healthcare, autonome Fahrzeuge, etc.
- Von Machine Learning zu Generative AI
- GenAI erstellt Musik, Bilder, Videos

### 3. Getting Started with AI on Jetson Nano
- Jetson Nano und Kamera einrichten
- Bilddaten für Klassifikationsmodelle sammeln
- Bilddaten für Regressionsmodelle annotieren
- Neuronales Netz auf eigenen Daten trainieren

### 4. Building A Brain in 10 Minutes
- Wie neuronale Netze aus Daten lernen
- Mathematik hinter einem einzelnen Neuron

### 5. Building Video AI Applications on Jetson Nano
- DeepStream-Pipelines für Videoverarbeitung erstellen
- Mehrere Videostreams verarbeiten
- Alternative Inferenz-Engines (YOLO) einsetzen

### 6. Building RAG Agents with LLMs
- Skalierbare Deployment-Strategien
- Microservices und Entwicklung
- LangChain-Paradigmen für Dialog-Management
- Aktuelle State-of-the-Art-Modelle

### 7. Accelerate Data Science Workflows with Zero Code Changes
- Vorteile einheitlicher CPU/GPU-Workflows
- GPU-Beschleunigung für Data Processing und ML
- Schnellere Verarbeitungszeiten mit GPU messen

### 9. Introduction to AI in the Data Center
- Grundlagen KI, Machine Learning, GPU-Architektur
- Deep Learning Frameworks und AI-Workload-Deployment
- Multi-System AI Cluster und Infrastrukturplanung
