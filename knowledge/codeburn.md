# CodeBurn — AI Coding Token Cost Tracker

Token-Kosten-Observability für KI-Coding-Assistenten. TUI-Dashboard zeigt Verbrauch und Kosten nach Task-Typ, Tool, Modell, MCP-Server und Projekt.

> "Works by reading session data directly from disk. No wrapper, no proxy, no API keys."

Multi-Provider: Claude Code, Codex, Cursor, Gemini CLI, GitHub Copilot und weitere per Plugin-System.

Besonderes Feature: **One-Shot Success Rate** — trackt wo der Agent "nails it first try vs. burns tokens on edit/test/fix retries". Dazu **Yield-Tracking** (experimentell): korreliert Ausgaben mit tatsächlichen Commits auf main.

13-Kategorie Task-Classifier, CSV/JSON-Export, Optimize-Funktion mit Copy-Paste-Fixes für erkannte Waste-Patterns, nativer macOS Menubar-App.
