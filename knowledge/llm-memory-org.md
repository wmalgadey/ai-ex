# llm-memory.org — AI Memory Vergleichsplattform

Community-maintained Open-Source-Plattform zum Vergleich von persistent Memory-Systemen. Stand April 2026: 19 Developer Tools, 4 User-facing Platforms, 20+ Vergleichsdimensionen.

## Was verglichen wird

**Developer Tools** (Coding Assistants):
- MCP-Integration, Vector vs. Graph Search, Cross-Machine Sync, Token Budgets

**User Memory Platforms** (Agents, Chatbots):
- Pricing, SDKs, Multi-Tenancy, Temporal Knowledge Graphs, Self-Improving Capabilities

Interaktive Tabelle mit Filter/Sort, JSON-basierte Datenstruktur für Community-Contributions.

## Einordnung

Ergänzt den [AI Memory Vergleich](ai-memory-vergleich.md) im ai-ex — dort eigene Tiefenanalyse von mem0, Supermemory, Vertex AI Memory Bank, ByteRover. llm-memory.org ist die breitere Community-Referenz mit mehr Systemen und regelmäßigen Updates.
