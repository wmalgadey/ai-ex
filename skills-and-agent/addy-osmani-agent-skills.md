# Addy Osmani — Agent Skills

**→ github.com/addyosmani/agent-skills** — MIT

Production-grade Engineering Skills für KI-Coding-Agenten. Erstellt von Addy Osmani (Google Chrome Team). 20 strukturierte Skills + 3 Spezialist-Personas, organisiert entlang des Entwicklungs-Lebenszyklus.

## Struktur

| Phase | Skills |
|---|---|
| **Define** | Idee verfeinern, Spezifikation schreiben |
| **Plan** | Task-Dekomposition |
| **Build** | Implementierung, Testing, UI Engineering, API Design |
| **Verify** | Browser-Testing, Debugging |
| **Review** | Code-Qualität, Simplification, Security, Performance |
| **Ship** | Git-Workflows, CI/CD, Deprecation, Dokumentation, Deployment |

**Spezialist-Personas:** code-reviewer, test-engineer, security-auditor

**Referenz-Checklisten:** Testing, Security, Performance, Accessibility

## Warum nicht kopieren

Der Inhalt der Skills ist dicht und vollständig. Ihn nach ai-ex zu übernehmen würde Pflege-Overhead erzeugen ohne Mehrwert — die Quelle ist gepflegt, MIT-lizenziert und direkt verwendbar.

## Was hier festgehalten wird

**Philosophie:** Skills als ausführbare Workflows, nicht generische Ratschläge. Jeder Skill enthält Verifikations-Gates und Anti-Rationalisierungs-Tabellen — explizit um Shortcuts zu verhindern.

Eingebettete Engineering-Konzepte: Hyrums Gesetz, Test-Pyramide, Trunk-Based Development — "Google's Engineering Culture" als Basis.

**Integration:** Setup-Dokumentation für Claude, Cursor, Gemini CLI verfügbar. Jede Skill-Directory enthält eine `SKILL.md`.
